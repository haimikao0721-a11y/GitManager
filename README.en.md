# Git Manager

A desktop tool for managing multiple Git accounts and local repositories.

## Features

- **Account Switching**: Manage multiple Git accounts (HTTPS & SSH) and switch commit identity and remote URLs per repository or in bulk.
- **Repository Scanning**: Scan local Git repositories, search and filter quickly, and open workspaces, terminals, or editors.
- **Workspace & History**: Manage branches, inspect branch commit nodes with right-click checkout, stage and commit changes, pull/push, stash, and browse commit graphs.
- **Environment Setup**: Manage Git credentials, SSH keys, and proxies.
