# Git管理器

一个用于管理多 Git 账号、本地仓库与工作台提交的轻量桌面工具。

## 启动

- **本地快捷方式**：双击桌面的 `Git管理器` 快捷方式（调用 `dist\启动.ps1`，启动本地核心 `gitcore.exe` 并打开 Edge 独立窗口，不额外拉起 `explorer.exe`，避免 `0xc0000142` 错误）。
- **GitHub 发布包**：下载并解压 `GitCore-v0.0.3-win-x64.zip` 后，双击目录中的 **`GitManager.cmd`** 即可启动。

## 主要功能

- **多账号与局部身份切换**：集中管理多个 Git 账号（HTTPS 与 SSH），支持全局默认账号切换，也支持在工作区顶栏针对当前仓库单独切换提交身份与 `HTTPS / SSH` 协议。
- **按盘符仓库导航与多视窗页签**：左侧边栏（支持 `Ctrl+B` 折叠/展开）直接按 `C 盘 / D 盘` 分组展示已扫描仓库并快速过滤；顶部栏支持多仓库视窗页签、跨仓库状态快照缓存、快速 `+` 选单及 `Alt+[` / `Alt+]` 切换。
- **统一工作台与右侧详情栏**：整合提交区、分组变更列表、分支/Stash 与彩色分支拓扑图；右侧可拖拽详情栏（`Ctrl+Shift+B`）随时查看提交详情、Diff 差异与仓储文件树。
- **差异对比与精细暂存**：支持文件/分块（hunk）级暂存与取消暂存、Stash 内容查看、深色/浅色/护眼三套主题下的红绿行底色 Diff，以及 `index.lock` 并发保护与残留锁一键清理。
- **环境配置**：在底部账号弹出菜单内直达账户管理、仓库批量切换与设置（Git 凭据过滤、SSH 密钥与代理管理）。

## 常用快捷键

- `Ctrl+K`：快速跳转命令面板
- `Ctrl+B`：收起 / 展开左侧仓库栏
- `Ctrl+Shift+B`：收起 / 展开右侧详情栏
- `Alt+[` / `Alt+]`（或 `Ctrl+PageUp` / `Ctrl+PageDown`）：切换前后已打开的仓库视窗
- `Ctrl+Enter`：提交代码
