# Git管理器

一个用于管理多 Git 账号与本地仓库的桌面工具。

## 启动

唯一的启动点：双击桌面的 `Git管理器` 快捷方式。

它会启动本地核心并打开 Edge 独立窗口。`dist` 内不再提供 `GitManager.exe` / `Git管理器.exe` 等重复启动器，避免误点。

> 快捷方式的目标是 PowerShell 启动脚本，不直接启动 `explorer.exe`，因此不会出现 `0xc0000142` 错误。

从 GitHub 发布包解压后，双击 `GitManager.cmd` 即可启动（发布包内不再包含重复的 exe 启动器）。

## 主要功能

- **多账号切换**：管理多个 Git 账号（HTTPS 与 SSH），支持单仓库或批量切换提交身份与远程地址。
- **仓库扫描**：自动扫描本地 Git 仓库，快速搜索、筛选并打开工作区、终端或编辑器。
- **工作区与提交历史**：支持分支管理、点击分支查看提交节点并右键签出、暂存与提交、拉取/推送、Stash 与彩色提交图。
- **环境配置**：管理 Git 凭据、SSH 密钥与网络代理。
